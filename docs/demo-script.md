# 60-second StayScape demo

Before recording: start both servers, use the default provider-free mode, load the map once, reset the view and keep attribution in frame. Use a desktop window around 1280x800. Rehearse the first chip so loading does not consume the recording.

| Time | Click / action | Say |
| --- | --- | --- |
| 0–8s | Show overview; gently pan | "StayScape explores 300 synthetic New York stays through a 3D city. No rental data was scraped." |
| 8–16s | Hover a model, then click it | "Models show property type, rings show rating, and selection connects the map, list and details." |
| 16–26s | Close details, open filters, set max price 250 | "Filters go to the backend. One result snapshot keeps every view in agreement." |
| 26–39s | Clear filters; click the first saved search chip | "This example works without a provider. Search enforces budget and amenities first, then ranks the eligible stays by vibe." |
| 39–48s | Point to explanation, interpreted filters and matching map | "The explanation and camera bounds come from actual results. Optional AI only interprets the request, with a validated keyword fallback." |
| 48–56s | Switch to a preconfigured 390px responsive viewport; collapse explorer | "Phone controls collapse to leave space for the map. Attribution stays visible, and reduced-motion preferences are respected." |
| 56–60s | End on map and credits | "The tradeoff is a focused, reproducible portfolio demo rather than a live booking platform." |
